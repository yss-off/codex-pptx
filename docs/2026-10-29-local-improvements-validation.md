## 改动范围

- 指南：标题连读与页间关系检查；按需用真实内容预览代表页；分开判断叙事、视觉、文件与现场讲述；保留用户确认边界，不新增通用 Pro 审阅或逐页审批要求。
- 校验：分别报告当前、遗留、新增、忽略的 XSD 诊断及无 schema 的部件。诊断按部件和不同消息计数，不等于有问题的 XML 节点总数。
- 生成：`pptx_helpers.js` 提供等比例容纳、居中裁剪和端点连线；验证真实生成图像框、裁剪区域、八方向箭头及备注随页序关联。
- 局部修改：`compare_decks.py` 提供 `palette`、`layout`、`reorder` 检查，页码按放映顺序解析。`reorder` 仅检查纯重排，不包含主动修改可见页码。

## 仍然存在的边界

- PptxGenJS 4.0.1 输出的 `notesMasterIdLst` 顺序被当前 XSD 判为错误，生成库源码另有兼容性说明。本次不修改安装库或静默调整该顺序。测试证明能发现这个已知问题，不证明原始生成文件完整有效。
- bundled core-properties XSD 对 `dcterms:created` 的引用无法解析；此前通用忽略规则已覆盖该消息。本次保留规则并显式报告限制，没有把它当成文档正文损坏，也不声称完整检查了 core properties。
- XSD 检查使用现有扩展命名空间预处理；成功只表示所检查范围通过。
- 差异工具要求稳定的 slide-part 身份，不按语义匹配重新生成的演示文稿；不能替代视觉、科学内容、可访问性或 PowerPoint 实机检查。
- 指南的叙事和审美改进尚未通过新的完整用户制作任务评估；脚本测试和示例渲染不能证明用户一定觉得更美观。

下一步是 review 本地差异；不自动发布或更新已安装插件。

## Pro 审阅后的本地修复

仍然只修改本地仓库；没有提交、推送、发布或同步安装缓存。

- 配色范围检查纳入 presentation 默认样式及其全局样式依赖。全局变化无法归属单页时，部分页范围保守拒绝；全页改色仍可通过。
- 布局模式只允许既有 slide/layout/master XML 内的布局和样式调整，保留正文（包括继承文本）、图片等内容引用、播放设置及超链接动作；冻结备注、关系文件和其他依赖部件。切换版式或改写依赖需要单独审查。
- 重排模式比较完整页面 ID 条目，仅忽略条目排列顺序，不再丢弃整个列表。
- imageCrop 使用最长边为 1 英寸的比例参数，避免 PptxGenJS 4.0.1 在虚拟尺寸达到 100 时混用 EMU。真实导出测试覆盖普通图、长条横竖图和阈值。
- 正文比较允许等价 run 拆分，保留段落和显式换行；带链接文字按覆盖范围和动作比较，允许等价拆分但拒绝改链接动作或覆盖范围。
- 基线摘要明确“不比较相同诊断的实例数和位置”，用重复负尺寸实例验证此既有边界。指南收紧强制多样化、默认子代理和全部加粗的旧表述。
